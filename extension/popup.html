Privacy & settings

History retention

Saved summaries are stored only in this Chrome profile. Older entries are removed when the extension opens.

What leaves this device?

When you summarize, the text you pasted and your selected summary options are sent to Google Gemini through the local Node.js backend. The backend stores aggregate usage counters, not post content. Feedback, preferences, and optional history remain in Chrome local storage.

No LinkedIn page access, cookies, automatic collection, or remote analytics are used.

Data controls

Export includes saved source text and summaries. Keep the file private.

Keyboard shortcuts

Ctrl + Enter / ⌘ + Enter summarizes while this popup is open.

Ctrl + Shift + L opens the extension on Windows/Linux. On Mac use ⌘ + Shift + L. You can change this in chrome://extensions/shortcuts.
