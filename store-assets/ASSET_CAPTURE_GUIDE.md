# Store screenshot capture guide — V9

Capture screenshots from the actual unpacked V9 extension in Chrome after starting the local server and configuring a provider. Use non-sensitive sample post text and confirm the disclosure has been accepted.

Suggested frames:
- Summary result showing General or Technical mode and structured extraction.
- Settings view showing profile preferences and local feedback controls.
- History view with local search results.

Screenshots must accurately represent the shipped `0.9.0` UI. Do not use previews as real store screenshots, imply hosted accounts, or imply automatic LinkedIn feed access.
